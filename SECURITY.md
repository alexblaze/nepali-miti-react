# Security Policy

Only the latest minor version receives fixes.

Please report vulnerabilities privately via
[GitHub Security Advisories](https://github.com/alexblaze/nepali-miti-react/security/advisories/new), not public issues.
You will get a response within 7 days.

`nepali-miti` has no runtime dependencies and does no I/O. Incorrect calendar data is a correctness bug, not a
security issue: please open a normal issue for it.
