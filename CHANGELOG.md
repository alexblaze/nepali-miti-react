# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project uses
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-02

### Added

- `NepaliDatePicker`: text input with a calendar popup. Supports typed dates in English or Devanagari digits,
  controlled and uncontrolled modes, `minDate`/`maxDate`/`isDateDisabled`, Today and Clear buttons, a hidden form
  field and Nepali/English labels.
- `NepaliCalendar`: inline month calendar with WAI-ARIA grid keyboard navigation, optional AD day numbers,
  Saturday highlighting and month/year selects.
- Default stylesheet `nepali-miti-react/styles.css` with CSS variables and automatic dark mode.
- Works with React 18 and 19; marked `"use client"` for Next.js App Router.
